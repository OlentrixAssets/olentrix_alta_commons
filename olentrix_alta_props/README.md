# Alta Commons props

The custom props from the Alta Commons map as a stand-alone resource. Drop the folder in your resources, `ensure olentrix_alta_props`, then place them by name in your own maps.

| Model | What it is |
|---|---|
| `ac_cafeset` | cafe table with four chairs and a parasol |
| `ac_bench` | park bench |
| `ac_parklamp` | park lamp |
| `ac_sakura` | cherry blossom tree |
| `ac_rosel_blush` | rose bush, blush |
| `ac_rosel_pink` | rose bush, pink |
| `ac_rosel_red` | rose bush, red |
| `ac_rosel_white` | rose bush, white |
| `ac_booth` | gate security booth (its door is ac_shackdoor) |
| `ac_shackdoor` | security booth door |
| `ac_door` | shop door |
| `ac_entdoor` | apartment entrance door |
| `ac_svcdoor` | service door |
| `ac_pedgate` | pedestrian gate leaf |
| `ac_egate` | sliding estate gate |
| `ac_mgate` | sliding main gate |
| `ac_rollleaf` | roller door leaf |
| `ac_bararm` | barrier arm |

The doors and gates are plain models; how they open is up to your own map or scripts. The Alta Commons map already contains these files, so this pack is only needed without it.
